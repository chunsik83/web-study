# 영업 리포트 대시보드

[Tabler](https://tabler.io/) 관리자 템플릿을 가져와 상담 실적 화면으로 바꿔본 연습 페이지입니다.
단일 파일 `main.html` 하나에 2,200줄 넘게 들어 있습니다.

## 실행

`main.html`을 브라우저로 열면 됩니다. CSS와 JS는 모두 CDN에서 불러옵니다(인터넷 연결 필요).

## 사용 중인 외부 라이브러리

| 라이브러리 | 용도 |
|---|---|
| Tabler Core 1.0.0-beta17 | 전체 UI (부트스트랩 5 기반) |
| ApexCharts 3.35.3 | 대부분의 차트 |
| c3.js 0.7.20 + d3.js 5 | "개발 활동" 영역 차트 |
| jQuery 3.6.3 | c3 차트 코드에서 사용 |

## 원래 템플릿에서 고친 것

원본은 Tabler 데모를 받아서 쓴 것이라 `../admin/dist/...` 같은 **로컬 경로**를 참조하고 있었는데,
그 `admin` 폴더가 저장소에 없어서 **스타일이 전부 깨지고 자바스크립트 에러가 13번 발생**하던
상태였습니다. 다음을 고쳤습니다.

1. **CSS/JS 경로를 전부 CDN 주소로 교체** — 이제 파일 하나만 열면 동작합니다.

2. **RequireJS shim 추가** — 원본 `charts-c3/plugin.js`가 `require([...], fn)` 형태의 모듈 로더를
   제공하고 있었습니다. 그 파일 없이 CDN 라이브러리를 쓰면서 차트 코드는 그대로 두려고
   최소한의 대체 함수를 넣었습니다.

3. **`tabler.colors` → `tabler.getColor()`** — 차트 코드가 `tabler.colors["blue"]`를 쓰고 있었는데,
   **`tabler.colors`는 Tabler 배포 파일 어디에도 없습니다.** 즉 원래 `admin` 폴더가 있었더라도
   이 줄에서 에러가 났을 코드입니다. Tabler가 제공하는 정식 API는 `tabler.getColor("blue")`이고,
   `#206bc4`를 돌려줍니다.

   > 참고로 `tabler.min.js`가 만드는 `window.tabler` 객체는 `Object.freeze`되어 있어서,
   > `window.tabler.colors = {...}` 처럼 속성을 나중에 끼워넣으려 해도 조용히 무시됩니다.

4. **없는 차트 컨테이너 방어** — 원본 데모에서 화면 블록만 지우고 차트 초기화 코드는 남아 있어서,
   페이지를 열 때마다 "Element not found" 에러가 12번 났습니다. 컨테이너가 있을 때만
   차트를 만들도록 조건을 붙였습니다. 코드는 지우지 않고 남겨두었으니, 해당 화면 블록을
   되살리면 차트도 함께 살아납니다.

   현재 컨테이너가 없어 동작하지 않는 차트: `chart-revenue-bg`, `chart-new-clients`,
   `chart-active-users`, `chart-mentions`, `sparkline-activity`, `chart-development-activity`,
   `sparkline-bounce-rate-1` ~ `-6`

5. **깨진 링크 정리** — 존재하지 않는 페이지(`index2.html`, `index11.html` 등)로 향하던
   내비게이션 링크 10개를 `#`로, 저장소에 없는 `favicon.png` 참조를 제거했습니다.

## 남은 과제

- **상담사 이름 20명이 실명으로 하드코딩되어 있고, 표에도 실명이 그대로 나옵니다.**
  공개 저장소라면 가명이나 `상담사1` 같은 값으로 바꾸는 것을 권합니다
  (`main.html`의 `<select name="name">` 부분과 "금일 상담기록" 표)
- 차트 숫자와 표 데이터가 전부 하드코딩된 정적 화면입니다. 실제 데이터를 붙이려면 서버가 필요합니다
- 위 4번의 죽은 차트 코드(약 700줄)는 화면을 되살릴 생각이 없다면 지워도 됩니다.
  같이 지운다면 `c3` / `d3` / `jQuery` 스크립트 태그 3줄도 함께 뺄 수 있습니다
- 내비게이션이 가리키던 다른 화면들은 만들어지지 않았습니다
- 2,200줄 단일 파일이라, 헤더/사이드바/차트를 나누면 관리하기 쉬워집니다
